# Getting help

- **Questions, ideas and "how do I…?"**: ask in
  [Discussions](https://github.com/sigta-hq/ui/discussions). Search there
  first, and include the component and a short Blade snippet.
- **Something is broken**: open a
  [bug report](https://github.com/sigta-hq/ui/issues/new?template=bug_report.yml)
  with the versions you use and the smallest snippet that shows it.
- **Something is missing**: open a
  [feature request](https://github.com/sigta-hq/ui/issues/new?template=feature_request.yml).
- **A security problem**: report it privately, as described in
  [SECURITY.md](SECURITY.md).

Before asking, it is worth checking:

- the [README](README.md) for installation, theming and the custom loader
- `sigta-components.md` in your app (written by `php artisan sigta:install`),
  which lists every component, prop and variant
- the [releases](https://github.com/sigta-hq/ui/releases) for breaking
  changes, if something stopped working after an update

Sigta UI is maintained by Sigta ApS alongside client work. Support here is
best effort and there is no guaranteed response time.
